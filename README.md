# مدیریت هزینه‌ها و مصرف سیگار

یک وب‌اپلیکیشن برای مدیریت بودجه، ثبت هزینه‌ها و کنترل مصرف سیگار.

## امکانات
- ثبت و مدیریت هزینه‌ها
- نمایش نمودارهای مالی
- محاسبه و پیگیری مصرف سیگار
- ذخیره اطلاعات در مرورگر
- همگام‌سازی اطلاعات با Supabase

## تکنولوژی‌ها
- HTML
- CSS
- JavaScript
- Chart.js
- Supabase

## اجرا
فایل index.html را در مرورگر باز کنید.
